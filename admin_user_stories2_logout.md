# User Story: Admin Portal Logout

**Title:**
_As an admin, I want to log out of the portal, so that I can protect system access when my session is complete._

**Acceptance Criteria:**
1. Prominent "Log Out" button accessible on all admin portal pages.
2. Clicking "Log Out" immediately invalidates the active session and clears local session tokens.
3. User is redirected to the public login page after logging out.

**Priority:** High
**Story Points:** 1
**Notes:**
- Auto-logout after 15 minutes of inactivity as an extra security measure.
