# User Story: Patient Portal Login

**Title:**
_As a patient, I want to log into the portal, so that I can access my dashboard and manage my bookings._

**Acceptance Criteria:**
1. Login interface accepting patient email and password.
2. Authenticates user and grants access to the patient dashboard.
3. Dashboard displays summary of account activities and links to manage active/past bookings.

**Priority:** High
**Story Points:** 3
**Notes:**
- Provide a "Forgot Password" link on the login page for credential recovery.
