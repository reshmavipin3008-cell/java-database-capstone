# User Story: View Upcoming Appointments

**Title:**
_As a patient, I want to view my upcoming appointments, so that I can prepare accordingly._

**Acceptance Criteria:**
1. Dedicated "My Appointments" section in patient portal displaying future bookings.
2. Displays appointment date, time, doctor's name, specialty, and consultation status/location.
3. List sorted chronologically with closest upcoming appointment at the top.

**Priority:** Medium
**Story Points:** 2
**Notes:**
- Add options for downloading calendar events (.ics) or setting reminders.
