# User Story: Update Doctor Profile Information

**Title:**
_As a doctor, I want to update my profile with my specialization and contact information, so that patients have accurate and up-to-date details._

**Acceptance Criteria:**
1. Profile edit form allowing updates to specialization, contact number, bio, and consultation hours.
2. Inputs validated (e.g., proper phone number formatting) prior to saving.
3. Updated details immediately reflect across public doctor directory and patient booking views.

**Priority:** Medium
**Story Points:** 3
**Notes:**
- Restrict critical credential fields (like License Number) to admin-only editing for compliance.
