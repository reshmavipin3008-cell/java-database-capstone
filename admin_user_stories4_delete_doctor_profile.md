# User Story: Delete Doctor Profile

**Title:**
_As an admin, I want to delete a doctor's profile from the portal, so that inactive or former staff are removed from the system._

**Acceptance Criteria:**
1. "Delete" or "Deactivate" option available on doctor management records.
2. Confirmation modal asking the admin to confirm deletion before proceeding.
3. System checks for existing/upcoming patient appointments before soft-deleting or archiving the profile.

**Priority:** Medium
**Story Points:** 3
**Notes:**
- Perform a soft-delete in the database to preserve historical medical and appointment records.
