# User Story: Patient Sign Up

**Title:**
_As a patient, I want to sign up using my email and password, so that I can create an account and book appointments._

**Acceptance Criteria:**
1. Registration form capturing user's full name, valid email address, and secure password.
2. Password validation rules applied (minimum length and character complexity).
3. Account created successfully upon submission with a confirmation message and redirect to login/dashboard.

**Priority:** High
**Story Points:** 3
**Notes:**
- Ensure duplicate email check prevents registering multiple accounts under the same email.
