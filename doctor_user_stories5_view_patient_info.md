# User Story: View Patient Information

**Title:**
_As a doctor, I want to view patient details for upcoming appointments, so that I can properly prepare for consultations._

**Acceptance Criteria:**
1. Doctor can click on an upcoming appointment to view associated patient profile details (e.g., age, contact, medical notes/reason for visit).
2. Data displayed complies with patient privacy and access permissions.
3. Information made easily readable in a quick summary modal or panel before consultation starts.

**Priority:** High
**Story Points:** 3
**Notes:**
- Ensure log entries are created whenever patient records/details are accessed (HIPAA compliance consideration).
