# User Story: Manage Schedule and Unavailability

**Title:**
_As a doctor, I want to mark my unavailability, so that patients only see and book available time slots._

**Acceptance Criteria:**
1. Interface to set recurring working hours and select specific dates/times as unavailable (e.g., time off, meetings).
2. Marked unavailable slots immediately block patient bookings for those time ranges.
3. Prompt warning shown if marking unavailability conflicts with existing appointments.

**Priority:** High
**Story Points:** 5
**Notes:**
- Provide option to cancel/reschedule existing bookings if emergency unavailability is declared.
