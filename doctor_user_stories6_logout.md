# User Story: Doctor Portal Logout

**Title:**
_As a doctor, I want to log out of the portal, so that I can protect patient and personal data when away from my device._

**Acceptance Criteria:**
1. Clear "Log Out" control accessible from the doctor dashboard top bar.
2. Action revokes active session state and redirects to the login screen.
3. Unsaved profile edits prompt a confirmation warning prior to session termination.

**Priority:** High
**Story Points:** 1
**Notes:**
- Enforce automatic session timeout after periods of inactivity to protect sensitive medical data.
