# User Story: Doctor Portal Login

**Title:**
_As a doctor, I want to log into the portal, so that I can manage my appointments securely._

**Acceptance Criteria:**
1. Authentication form for doctors using credentials (email/username and password).
2. Directs doctor to their customized dashboard upon successful authentication.
3. Access restricted strictly to authorized medical provider features and patient privacy controls.

**Priority:** High
**Story Points:** 3
**Notes:**
- Implement role-based authorization to ensure doctors only see their assigned appointments.
