# User Story: Add Doctor to Portal

**Title:**
_As an admin, I want to add new doctor profiles to the portal, so that patients can view and book appointments with them._

**Acceptance Criteria:**
1. Form allowing input of doctor details (full name, specialty, contact details, medical license ID, available schedule).
2. Validation on all required fields before submission (e.g., proper email format, non-empty fields).
3. Success confirmation displayed and the new doctor profile instantly appears in the active provider list.

**Priority:** High
**Story Points:** 5
**Notes:**
- Ensure unique constraints on doctor license numbers and email addresses to prevent duplicate entries.
