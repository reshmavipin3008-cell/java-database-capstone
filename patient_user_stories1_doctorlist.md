# User Story: View List of Doctors Without Login

**Title:**
_As a patient, I want to view a list of doctors without logging in, so that I can explore my options before registering._

**Acceptance Criteria:**
1. Publicly accessible doctor directory page available without requiring authentication.
2. Displays key details for each doctor (e.g., full name, specialty, bio, and profile picture).
3. Search or filter functionality available by medical specialty or location.

**Priority:** High
**Story Points:** 3
**Notes:**
- Hide sensitive action buttons (like "Book Now") until the user signs in or registers.
